# 게임 기획서 (GDD) — 소문의 낙원 (Cocktail Bar Story)

모바일 퍼스트 칵테일 바 운영 게임. 실제 칵테일 레시피대로 조주하고, 발주로 메뉴를 넓혀가는 시뮬레이션.

## 핵심 컨셉

- **메인 씬 (바텐더 POV)**: 카운터 너머로 손님을 마주 보며 운영 — 주문 접수, 서빙, 손님 반응
- **조주 씬 (POV)**: 붓기(기기 기울이기), 셰이킹(폰 흔들기), 스터링(터치 드래그)
- **실제 레시피**: IBA 공식 스펙 기준. 레시피북은 실생활에서도 참고 가능한 교육적 가치
- **발주 → 메뉴 확장**: 초기 자금으로 한정된 보틀만 보유 → 벌어서 발주 → 레시피 해금 → 메뉴 등록

## 코어 루프

```
[메인/POV] 손님 입장 → 착석 → 주문
    ├─ 원하는 칵테일이 메뉴에 있음 → [POV 조주] → 서빙 → 대금 + 팁(정확도×인내심 배율)
    └─ 메뉴에 없음 → "아쉽네요, 그럼 ○○로 할게요" (미보유 메뉴 힌트 노출) → 대금만, 팁 없음
영업 종료 → 정산 → [발주] 보틀 구매 → 레시피 해금 → 메뉴 등록 → 다음 날
```

## 조주 미니게임 (POV)

| 동작 | 입력 | 판정 |
|---|---|---|
| 붓기 (pour) | 보틀 선택 → **꾹 누르면 병이 점점 깊게 기울고**(20°부터 나옴, 최대 85°·80ml/s), **손을 떼도 병이 돌아오는 동안 관성으로 조금 더 나옴** — 오버슈트 예측이 스킬 | 목표량 대비 오차율 |
| 얼음 (ice) | 얼음 버튼 → 현재 용기에 추가. 셰이크→셰이커, 하이볼/락→잔, 쿠페/마티니/마가리타→넣으면 감점 | 요구 위치 일치 여부 |
| 셰이킹 (shake) | 셰이크 레시피는 **셰이커에서 조리** (재료를 셰이커에 붓고 얼음+흔들기). **실제 폰 흔들기**, 폴백: 화면 문지르기 | 목표 시간 대비 흔든 시간 |
| 잔에 따르기 (strain) | 셰이커 조리 후 버튼 → 셰이커가 기울며 잔으로 옮겨 붓는 연출 | 셰이크 레시피 필수 |
| 스터링 (stir) | 바 스푼을 원형 드래그 | 회전 각도 누적 → 목표 시간 환산 |
| 서빙 | 완성 버튼 | 레시피 채점 → 손님 리액션 |

잔 10종: 하이볼 / 락 / 쿠페 / 마티니 / **마가리타(2단 보울)** / 리큐르(푸스카페·B-52) / 사워 / 필스너 / 콜린스 / 와인. 물줄기는 포물선 곡선 + 흔들림 + 물방울 + 착지 스플래시로 연출.
채점 가중치: 계량 55% · 기법(셰이크/스터/스트레인/**플로팅**) 25% · 얼음 10% · 가니시(+**리밍**) 10%.

**플로팅(레이어링)**: `float` 스텝은 유량 0.38 이하(병을 살짝만 기울여)로 끝까지 부어야 층이 유지된다. 세게 부으면 전부 섞이고, 젓기·스트레인도 층을 없앤다. 층은 잔 안에 색 밴드로 렌더링 (푸스 카페 3층, B-52 3층, 데킬라 선라이즈·싱가폴 슬링 토핑).

**리밍(프로스팅)**: 카운터의 리밍 접시 탭 → 소금/설탕 선택 → 잔 테두리에 묻는다 (마가리타=소금, 키스 오브 파이어=설탕). 잘못된/불필요한 리밍은 감점.

**선반 UI**: 재료 58종을 기주/리큐르/주스·시럽 카테고리 버튼 3개로 정리 — 탭하면 보유 보틀 그리드 모달에서 선택.

**소품 인터랙션 UI**: 조주는 버튼이 아니라 카운터 위 도구를 직접 만진다 — 도구통(스푼·지거) 탭=스터, 얼음통 탭=얼음(용기로 날아가는 연출), 가니시 트레이 탭=픽커(레몬 슬라이스·라임 웨지·오렌지 슬라이스·체리·올리브·민트 중 선택, **조주기능사 실기 스펙 기준** — 위스키 사워=레몬+체리, 올드 패션드=오렌지+체리, 마티니=올리브 등), 셰이커 짧은 탭=셰이킹(꾹 누르면 붓기와 구분). 장식: 커팅보드+라임, 바 타월. 화면 텍스트 설명은 없고 [레시피 📖] 버튼이 실시간 체크리스트 오버레이를 토글한다.

**레시피 암기 보상**: 조주 중 레시피 오버레이를 한 번이라도 열면 그 잔의 최종 점수에 **80% 보정**이 걸린다. 안 보고 만들어야 만점 — 레시피북의 교육적 가치(암기 유도)와 숙련 보상을 겸한다. 결과 토스트에 `📖 레시피 참고 · 80%`로 표시.

**첫 영업 안내**: 새 게임 첫 바 진입 시 조작 안내 팝업(6줄, 아이콘+5단어 이내)이 뜨고, 닫기 전까지 시계·손님 스폰이 정지한다. 슬롯별 1회만 표시(`tutorialSeen` 저장).

**핀볼 미니게임**: 바 왼쪽의 오락기를 탭하면 핀볼(공 3개, 범퍼 3개, 좌/우 터치 플리퍼). 영업은 뒤에서 계속 흘러가고, 손님이 착석하면 "🔔 손님이 기다려요!" 배너 + 바로 가기 버튼이 뜬다. 세션 최고 기록 저장.

**채점(부분 점수제)**: 재료 누락/과잉(-큰 감점), 계량 오차(±10% 무감점, 이후 비례 감점), 기법 시간 오차. 결과 화면에서 항목별로 무엇이 틀렸는지 표시.

**팁 공식**: `팁 = 기본가 × 0.3 × 정확도(0~1) × 인내심 배율(0.2~1)`

## 경제/진행

- 시작 자금 100,000₩, **일일 운영비 50,000₩** (영업 종료 시 차감 — 매출/운영비/순익 정산 표시)
- 가격은 2026-08 시세 조사 기반: 병값은 국내 소매가(고든스 2만, 캄파리 4.5만, 라이 5만 등), 판매가는 서울 소형 1인 바 기준(하이볼 9천 ~ 맨해튼/올드패션드 1.7만)
- 운영비는 실제(일 9.6만~14.6만)의 60~70% 수준으로 낮춰 "잘하면 순익 2~4만, 못하면 적자" 밸런스
- **레시피 36종 = 조주기능사 실기 31종(블렌더 4종·전통주 5종 제외 전체) + 게임용 5종(진토닉·스크류드라이버·하이볼·모히토·에스프레소 마티니)**
- Tier 1 (빌드): 진토닉, 쿠바 리브레, 스크류드라이버, 블랙 러시안, 씨브리즈, 모스코 뮬, 키르, 레몬 스쿼시 등
- Tier 2 (셰이킹/스터): 다이키리, 위스키 사워(사워 글라스+탄산수), 마가리타(소금 리밍), 사이드카, 그래스호퍼, 브랜디 알렉산더, 준벅, 진 피즈, 뉴욕 등
- Tier 3 (플로팅/고급): 푸스 카페, B-52, 싱가폴 슬링, 키스 오브 파이어(설탕 리밍), 마티니, 맨해튼, 허니문 등
- 보틀 가격은 실제 시세 반영 (믹서 1.5~8천 / 기주 1.7~5만 / 리큐르 1.5~4.5만)
- 재고는 ml 단위 차감 (보틀 700ml, 믹서 1000ml)

## MVP 범위

**포함**: POV 바(손님 4석, 인내심, 주문 말풍선, 서빙 후 반응 연출+채점 토스트), POV 조주(틸트 pour/shake/stir/garnish), 15종 레시피, 발주 상점, 메뉴 등록, 채점·팁, 일차 진행+운영비 정산, 세이브 슬롯 3개(localStorage), **손님 페르소나 10명·대화·단골 시스템** (`docs/04-customer-system.md`)

**제외(post-MVP)**: 머들링/리밍/스트레인 판정, 자이로 프리 푸어, 얼음 종류, 가니시 선택지, 단골 서사·대화, 과장 실패 연출(폭발 등), 사운드, 실제 아트(현재 절차 생성 플레이스홀더), 광고/IAP 없음 유지
