# UI 스타일 가이드 (2026-08 레퍼런스 조사 기반)

레퍼런스: VA-11 Hall-A(다크+네온 1색 포인트), Coffee Talk(저채도 브라운, 기능 UI는 플랫),
Stardew Valley(균일 보더), 코지 장르 버튼 관례(플랫+하단 뎁스, 프레스 시 가라앉음).

## 폰트

- **Galmuri11** (Regular+Bold, SIL OFL 1.1) — `public/fonts/` 번들, 한글 11,172자 전체
- 폴백 노출 금지: 폰트 로드 대기 후 게임 시작 (`main.ts`)
- 픽셀 폰트 원칙: 정수 크기만, letter-spacing/이탤릭 금지, `roundPixels: true`
- 디스플레이용이 더 필요하면 같은 패밀리 Galmuri14 추가 (약 +550KB)

## 컬러 토큰 (`ui/theme.ts` COLORS)

| 토큰 | 값 | 용도 |
|---|---|---|
| bg / panel / panelLight | #12080f / #1e1016 / #2e1a24 | 배경·패널 (같은 색조 명도 단계) |
| wood 계열 | #59331d / #33200f / #7a4a28 | 카운터·가구 |
| accent / accentDark | #e8a33d / #b87a20 | **주 액션 1색** (버튼·강조) |
| neon | #ff4f9a | **면 채우기 금지** — 간판·특수 강조의 보더/텍스트/글로우 전용, 화면당 1~2곳 |
| cream | #f2e6d0 | 본문 텍스트 (보조는 알파 0.55) |
| ok / danger | #5fbf67 / #d84343 | 상태 피드백 순간에만 |

색 절제: 한 화면에 면으로 등장하는 색은 3개 이하.

## 컴포넌트 스펙

- **버튼** (`art.buttonTexture`): 단색 본체 + 하단 뎁스 5px(`shade(-0.42)`), radius **8 고정**,
  보더 rgba(0,0,0,0.25) 1.5px. 광택 그라데이션·상단 하이라이트 금지.
  프레스: y+4px 가라앉는 트윈 (scale 트윈 아님)
- **패널** (`art.panelTexture`): #170d12 96% + radius 14 + 앰버 보더 알파 0.32 1.5px
- **텍스트 그림자**: 0/1px, blur 2, alpha 0.45 — 가독성 용도로만
- **말풍선**: 크림 #f7f1e3, radius 14 (대화 카드 초상화엔 앰버 프레임 고려)

## DON'T

- 유리 광택 그라데이션, 상단 흰 하이라이트, 요소별 외곽 글로우
- 화면마다 다른 radius/보더/그림자 값 (radius 토큰: 8=버튼, 14=패널)
- 네온·앰버·초록·빨강 동시 면 등장
- 픽셀 폰트 소수점 크기, 시스템 폰트 폴백 노출
- blur 큰 drop shadow 남발 (모달만 하드 섀도 허용)
