## 5. 콘텐츠 등급 설문 (IARC)

- 폭력·공포·사행성·비속어: 없음
- **약물·주류·담배: "주류에 대한 언급/묘사 있음" 체크** (게임 주제가 칵테일 조주)
- 예상 결과: 한국 청소년이용불가 또는 17+ 계열 — 설문에 솔직하게 답하면 자동 산정됨

## 6. 데이터 보안 설문

- 데이터 수집: **아니요** — 진행 상황·설정 전부 기기 내 저장(local storage), 서버 전송 없음
- 데이터 공유: **아니요** (제3자 SDK 없음)
- 암호화·삭제 요청: 해당 없음 (수집 자체가 없음; 앱 삭제 시 데이터도 삭제)
- 모션 센서는 셰이킹 조작 판정에만 실시간 사용, 저장·전송 없음

## 7. 업로드 절차 요약

1. **서명 Secrets 등록** (최초 1회): `UPLOAD_KEYSTORE_BASE64`, `UPLOAD_KEYSTORE_PASSWORD` → Actions 재실행 → `cocktail-bar-release-aab` 아티팩트에서 `app-release.aab` 확보
2. Play Console → 앱 만들기 (이름·패키지는 위 표)
3. 스토어 등록정보: §3 텍스트 + §2 이미지 입력, 개인정보처리방침 URL 입력
4. 콘텐츠 등급(§5)·데이터 보안(§6)·타깃층(만 18세 이상 권장) 설문 완료
5. **내부 테스트** 트랙에 AAB 업로드 → 테스터 등록 → 검토 제출
6. (개인 신규 계정) 비공개 테스트 12명·14일 요건 충족 후 프로덕션 승격
