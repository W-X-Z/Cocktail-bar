| 파일 | 규격 | 용도 |

스크린샷 구성: ① 타이틀 ② 바(손님 대화) ③ 붓기 ④ 레시피 체크리스트 ⑤ 셰이커+얼음 ⑥ 핀볼 ⑦ 발주 상점.
권장 업로드 순서는 ③→②→⑤→④→⑥→⑦→① (플레이 장면 먼저).

지금 소문의 낙원의 문을 열어보세요. 🍹

## 콘텐츠 등급 설문 (IARC)

- 폭력·공포·사행성: 없음
- **약물·주류·담배: "주류에 대한 언급/묘사 있음" 체크** (게임 주제 자체가 칵테일 조주)
- 결과 예상: 한국 청소년이용불가 또는 17+ 계열 등급 — 설문에 솔직하게 답하면 됨

## 데이터 보안 설문

- 데이터 수집: **아니요** (모든 진행 상황은 기기 내 저장, 서버 전송 없음)
- 데이터 공유: **아니요**
- 데이터 암호화/삭제 요청: 해당 없음 (수집 자체가 없음)

## 업로드 순서 요약

1. `docs/06-release.md`대로 서명 Secrets 등록 → Actions 재실행 → 서명된 `app-release.aab` 다운로드
2. Play Console → 앱 만들기 → 위 등록정보/이미지 입력
3. 내부 테스트 트랙에 AAB 업로드 → 설문 완료 → 검토 제출
4. (개인 신규 계정) 비공개 테스트 12명·14일 요건 충족 후 프로덕션 승격
